Step-by-step guide

Build your own job search agent

An agent is a set of instructions that remembers how you search. You paste in a job description, and it tells you whether the role fits, then builds a tailored resume and an optional cover letter. This guide starts from zero: no coding, no terminal experience needed.

Time: about 45 minutes You need: a computer and a paid Claude plan You'll end with: your own working agent

2

What you're building

Three kinds of files, all plain text. Claude reads them every time you ask for help with a job.

The agent

Your rules: which roles you want, your dealbreakers, where you'll work, how you like to be coached. job-search-coach.md

The skill

The how-to for building resumes and cover letters: the template, the length limits, the "never invent anything" rule. resume-tailor

Your facts

Your real career history. The agent only uses what's in here, so it can't make things up about you. professional-experience.md

The starter kit gives you all three with blanks to fill in. In Step 7, Claude interviews you and fills them in, so you never have to edit a file by hand.

What you need before you start

  • A Claude plan. Claude Code needs a paid plan: Pro, Max, Team, or Enterprise. See plans.
  • Your current resume as a PDF, Word file, or pasted text. It's the raw material for your facts file.

  • A Mac or Windows computer. (Linux works too, with a few differences not covered here.)

Install Claude

Claude app
  1. Download the app for your computer:

  2. Open the downloaded file and finish installing. On a Mac, drag Claude into your Applications folder.
  3. Open Claude and sign in with your Claude account.
  4. Click the "Code" tab at the top of the sidebar. If you only see icons, hover over each one to see its name.

Terminal

First: what is a terminal?

A terminal is a window where you talk to your computer by typing instead of clicking. That's the whole idea. You type a short command, press Enter, and the computer does it. Claude Code runs inside it as a chat: you type a message, press Enter, and Claude replies.

A few things that make it less scary:

  • You only run the commands this guide gives you. Nothing happens until you press Enter.
  • You can't click inside it. Use the arrow keys.
  • To stop whatever is running, press Esc (or Ctrl + C).

1. Open a terminal

  • Mac: press Cmd + Space, type Terminal, press Enter.
  • Windows: press Win + X and choose Windows PowerShell (or Terminal). Your lines should start with PS.

2. Install Claude Code

Copy the command for your computer, paste it into the terminal (Cmd + V on Mac, Ctrl + V or right-click on Windows), and press Enter. It downloads the official installer from claude.ai and runs it. It shows no progress while it works, so wait until you see "Claude Code successfully installed!"

Mac
curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell
irm https://claude.ai/install.ps1 | iex

Windows says irm isn't recognized? You're in CMD, not PowerShell. Close it and open PowerShell with Win + X.

3. Check it worked

Close the terminal, open a new one, and run:

claude --version

You should see a version number. If it says "command not found", see Troubleshooting below.

5

Download the starter kit and put it somewhere easy to find

The starter kit is a folder with a generic version of my agent and skill: the structure, the rules, and a clean resume and cover letter template. All the blanks are yours to fill in. It contains none of my personal details.

Download the starter kit (.zip)
  1. Unzip it. Double-click the .zip file in your Downloads folder. You'll get a folder called job-search-agent-starter.
  2. Move that folder to Documents so it's easy to find. This is your job search folder from now on.

Where's the .claude folder? Folders that start with a dot are hidden. On a Mac, press Cmd + Shift + . in Finder to show them. On Windows, open File Explorer, then View, then Show, then Hidden items. You don't have to see it, since Claude will edit the files for you, but it helps to know it's there.

6

Open your folder in Claude

Claude works inside whatever folder you point it at. Pointing it at the starter kit folder is what makes your agent available.

Claude app
  1. In the Code tab, look at the row under the prompt box.
  2. Click the first control (the environment selector) and choose the top entry under Local, so Claude runs on your computer.
  3. Click the project folder control next to it, choose Open folder…, and pick job-search-agent-starter.
  4. Leave the Permission mode on Manual. Claude will then show you each change and wait for you to approve it.
Terminal

The terminal always has a "current folder", the place it's looking right now. You'll move it into your starter folder with cd (change directory).

Mac
cd ~/Documents/job-search-agent-starter
Windows PowerShell
cd $HOME\Documents\job-search-agent-starter

Shortcut: type cd and a space, then drag the folder from Finder or File Explorer into the terminal window. It fills in the path for you.

Now check you're in the right place. This lists what's in the folder, including hidden files. You should see .claude and START-HERE.md.

Mac
ls -a
Windows PowerShell
dir -Force

Then start Claude:

claude

The first time, it opens your browser so you can sign in. Claude may also ask whether you trust this folder. It's your own folder, so say yes.

Check that your agent is there

In the Claude chat box, paste this and press Enter:

What agents and skills can you see in this folder?

You should see job-search-coach and resume-tailor in the answer. If you don't, see Troubleshooting.

7

Let Claude interview you

This is the step that makes it yours. Instead of editing files, you answer questions. Have your current resume handy, because Claude will ask for it first.

Paste this into the Claude chat box:

Read START-HERE.md and everything in .claude/. Every [[double bracket]] is a blank for me to fill in. Interview me one question at a time to fill in all of them, starting with professional-experience.md. Ask me to paste my current resume first and use it to pre-fill what you can. Before saving anything, show me what you plan to write and wait for my OK. Do not invent anything I haven't told you.

Plan on about 20 minutes. Claude will ask about:

  • Your career history, with titles, companies, and dates exactly as they should appear
  • Your best bullets for each role, with outcomes first
  • The roles you want, the roles to skip, and your dealbreakers
  • Where you'll work: remote, hybrid cities, relocation
  • How you want to be coached

Be specific and honest. The agent only uses what's in your facts file, so a real number or a concrete result in here will show up in every resume. If you don't have a number, describe the change instead. Don't round up.

Review every change. In the app, approve each one with the buttons. In the terminal, press Enter to approve when Claude asks, or tell it what to change.

8

Test it on a real job

Find a job posting you're interested in, copy the whole description, and paste it in like this:

Here's a job I found: [paste the whole job description here]

What should happen:

  1. Assessment first. Claude tells you whether the role fits your criteria and why, then asks for your OK. It won't build anything yet.
  2. You say yes (or push back, and it adjusts).
  3. It builds the resume and saves it in the generated-resumes folder.
  4. It asks whether you want a cover letter. Say yes or no. Many roles don't need one.

Check the resume

  1. Open the file in generated-resumes in your browser (double-click it).
  2. Read every line for accuracy. Titles, dates, and claims should all match your real history. You're the final check.
  3. To save a PDF, print the page (Cmd + P or Ctrl + P), set the destination to Save as PDF, scale to 100%, and turn Background graphics on.

If something looks wrong, just tell Claude in plain language: "The summary sounds too formal. Make it warmer." or "That bullet overstates what I did. Tone it down." It fixes the file for you.

9

Tune it over time

Your agent gets better the more you use it. Whenever a result is off, ask Claude to change the agent, not just the output. A few examples to paste in:

Add this to my dealbreakers in the agent: [your new dealbreaker]. From now on, flag those roles and stop.
Resumes keep running to three pages. Tighten the length rules in the resume-tailor skill so they stay at two.
Add a step to my agent: when a posting lists a salary range, tell me whether it's at or above [your number].

After editing the agent or skill files, Claude picks up the changes within seconds. If it doesn't, close and reopen your session.

Later

Optional: back it up

Once your agent is working, it's worth keeping a safe copy so you can't lose it. The standard way is git (a history of your changes) plus a private GitHub repository (an online copy only you can see). You don't need to learn either. Ask Claude to do it:

Set up git in this folder and help me back it up to a private GitHub repository. Walk me through each step and tell me what I need to click or type.

Make it private. Your folder contains your real career history. When GitHub asks whether the repository is public or private, choose Private.

Troubleshooting

"command not found: claude" (terminal)

The installer put Claude somewhere your terminal doesn't look yet. Close the terminal and open a new one first. If it still fails on Mac, run these two lines, then open a new terminal:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

On Windows, if PowerShell says claude isn't recognized, see the official Windows fix.

Claude doesn't see my agent or skill
  • Make sure you opened the starter folder itself, the one that contains .claude, and not a folder above or below it.
  • Close the session and open it again. The first time agent files appear, Claude needs a fresh start.
  • Ask: What agents and skills can you see in this folder?
The install command shows an error with "syntax error" or HTML

The download link returned a web page instead of the installer. Try the command again. If it keeps happening, check whether Claude Code is available in your country, or use the install troubleshooting page.

The app shows an upgrade prompt or a 403 error on the Code tab

An upgrade prompt means you need a paid plan. For a 403 error, sign out of the app, sign back in, and restart it. The official fix has more.

The resume prints with a big gap in the middle

Ask Claude: The printed resume has a gap between sections. Check the file for forced page breaks and remove them. The template is built to avoid this, so it usually means a page-break rule snuck in.

I want to start over

Download the starter kit again and unzip it into a new folder. Your old folder isn't touched.

Good habits

  • You are the final check. The agent is built to never invent accomplishments, but you're the one sending the resume. Read every line.
  • Keep your folder private. Don't share the filled-in version or post it publicly. It has your real history.
  • Don't paste anything confidential from a current employer into your facts file.
  • Apply anyway. The agent can tell you whether a role fits, but it can't tell you whether you'll get it. Let real feedback guide the changes.
